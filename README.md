# lastseen.tools pour Windows

## Français

Dépôt officiel de téléchargement de **lastseen.tools** pour Windows.

lastseen.tools est un lecteur musical et un générateur de playlists pour
Windows, basé sur foobar2000.

### Télécharger l’application

Téléchargez `lastseen.tools-2.0-Setup.exe` depuis la
[release v2.0.0](https://github.com/lastseenat/lastseentools/releases/tag/v2.0.0),
puis lancez-le. L’installeur installe foobar2000 et Beefweb, ou reprend votre
foobar2000 existant.

### Prérequis

- Windows 10 ou Windows 11 en 64 bits
- Microsoft Edge WebView2 (généralement déjà présent dans Windows)

L’installeur contient les mentions tierces et les textes de licences associés.
Les sources de TagLib, utilisée par l’application, sont disponibles dans la
release (`taglib-2.2.1.tar.gz`).

### Version Android

Playlist Generator Mobile possède sa propre
[page de téléchargement](https://github.com/lastseenat/playlist-generator-mobile/releases).

### Vérification

Comparez l’empreinte SHA-256 de l’installeur téléchargé avec celle affichée
dans la release.

## English

Official download repository for **lastseen.tools** on Windows.

lastseen.tools is a music player and playlist generator for Windows, based on
foobar2000.

### Download the app

Download `lastseen.tools-2.0-Setup.exe` from the
[v2.0.0 release](https://github.com/lastseenat/lastseentools/releases/tag/v2.0.0),
then run it. The installer installs foobar2000 and Beefweb, or reuses your
existing foobar2000.

### Requirements

- 64-bit Windows 10 or Windows 11
- Microsoft Edge WebView2 (generally already included with Windows)

The installer includes third-party notices and the related license texts.
The source code of TagLib, used by the app, is available in the release
(`taglib-2.2.1.tar.gz`).

### Android version

Playlist Generator Mobile has a separate
[download page](https://github.com/lastseenat/playlist-generator-mobile/releases).

### Verification

Compare the SHA-256 checksum of the downloaded installer with the checksum
shown in the release.
