# lastseen.tools pour Windows

## Français

Dépôt officiel de téléchargement de **lastseen.tools** pour Windows.

lastseen.tools affiche la lecture en cours de foobar2000 et permet de la piloter
grâce au composant Beefweb.

### Télécharger l’application

Téléchargez `lastseentools-windows-public-v1.0.zip` depuis la
[release v1.0.0](https://github.com/lastseenat/lastseentools/releases/tag/v1.0.0),
extrayez l’archive, puis lancez `lastseentools Public V1.0.exe`.

### Prérequis

- Windows 10 ou Windows 11 en 64 bits
- foobar2000
- Beefweb actif sur `localhost:8880`
- Microsoft Edge WebView2 Runtime

L’archive contient également les instructions, les mentions tierces et les
textes de licences associés.

### Version Android

Playlist Generator Mobile possède sa propre
[page de téléchargement](https://github.com/lastseenat/playlist-generator-mobile/releases).

### Vérification

Comparez l’empreinte SHA-256 de l’archive téléchargée avec celle affichée dans
la release.

## English

Official download repository for **lastseen.tools** on Windows.

lastseen.tools displays the current foobar2000 playback and provides playback
controls through the Beefweb component.

### Download the app

Download `lastseentools-windows-public-v1.0.zip` from the
[v1.0.0 release](https://github.com/lastseenat/lastseentools/releases/tag/v1.0.0),
extract the archive, then run `lastseentools Public V1.0.exe`.

### Requirements

- 64-bit Windows 10 or Windows 11
- foobar2000
- Beefweb running on `localhost:8880`
- Microsoft Edge WebView2 Runtime

The archive also includes instructions, third-party notices, and the related
license texts.

### Android version

Playlist Generator Mobile has a separate
[download page](https://github.com/lastseenat/playlist-generator-mobile/releases).

### Verification

Compare the SHA-256 checksum of the downloaded archive with the checksum shown
in the release.
